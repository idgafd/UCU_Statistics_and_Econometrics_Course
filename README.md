# UCU_Statistics_and_Econometrics_Course

Structure:
- Assignment_1 — Descriptive Statistics & Probability Theory (real + simulated data); includes descriptive measures, visualizations, and correlation/association analysis on CEO compensation-type data
- Assignment_2 — LLN/CLT verification, confidence intervals, distribution fitting, hypothesis testing; includes simulations for LLN/CLT, CI with known vs estimated variance, plus applied probability modeling and hypothesis tests
- Assignment_3 — Linear Regression (Ames Housing): encoding categorical variables, transformations, inference, model fit; includes dummy encoding, missing data handling, log transforms, t-tests, and R vs adjusted R² analysis
- Assignment_4 — Regularization and tree-based methods (Ridge/Lasso, regression trees, bagging, random forest); includes linear vs ridge variance/shrinkage comparison, regression-tree split optimization/importance, and ensemble error vs number of trees
